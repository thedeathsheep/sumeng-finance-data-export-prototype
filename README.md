# 塑梦AI 财务数据看板原型

本原型用于演示总后台“财务数据看板＋人工维护＋Excel 导出”的产品方案。

在线地址：https://thedeathsheep.github.io/sumeng-finance-data-export-prototype/

代码推送到 `main` 后，由 GitHub Actions 自动构建并发布到 GitHub Pages。

## 核心口径

- 线上产品对象仍只有用户、团队和算力账户；企业或渠道身份只作为财务档案。
- 一份财务档案可以关联多个用户、团队或算力账户；同一线上账户同一时间只能归属一份有效档案。
- 财务客户类型固定为“个人 / 企业”，并随财务主体展示在各业务明细中。
- 系统已有数据标记为“系统同步”，不可在财务看板内直接改写。
- 线下财务资料标记为“人工录入”，允许编辑或作废，不允许物理删除。
- 人工记录保留创建、修改、关联积分流水和作废记录。
- 没有数据的字段统一显示并导出“/”。
- 积分与人民币金额分开表达；没有确认换算规则时不自动折算。
- 财务看板不直接修改积分。线下收款或退款涉及积分时，先在算力账户完成调整，再关联真实积分流水。
- 权限沿用总后台现有角色和权限配置机制。

## 看板模块

1. 客户及财务档案：客户主体、联系方式、账户状态、合同和开票资料。
2. 充值明细：线上订单、充值积分调整及人工录入的线下充值资料。
3. 消费明细：系统积分流水、三类积分扣减、计量依据及合同关联。
4. 月度汇总：按当前筛选条件动态汇总未作废的系统与人工记录。
5. 特殊业务：退款、清零、调账或冲红、手续费和取消订单；手续费按第三方商家后台账单按月、按渠道人工录入。

## 主要交互

- 新增财务档案，并关联多个线上用户、团队或算力账户。
- 录入对公转账、线下刷卡等线下充值资料，按“待收款 → 已收款待发放 → 已完成”闭环。
- 从算力账户返回后，为财务记录关联真实积分调整流水。
- 录入特殊业务，并可选择上传凭证或证明材料。
- 用户实付金额不扣减第三方手续费；手续费作为平台级月度费用单独登记，不关联单笔订单。
- 编辑、查看变更记录或作废人工记录。
- 按月份、线上对象类型和关联账户筛选。
- 选择五类工作表导出 Excel。

原型中的新增、编辑、作废与导出为交互演示，不连接真实财务数据。
