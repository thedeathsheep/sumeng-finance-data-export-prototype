# 塑梦AI 财务数据看板原型

本原型演示总后台财务数据看板、积分调整自动归类、退款资料补充和 Excel 导出。

## 核心口径

- 线上产品对象仍为用户、团队和算力账户；个人或企业仅为财务客户类型。
- 财务看板不提供线下充值、人工入账或人工新建特殊业务入口。
- 后台调整充值积分时必须选择业务性质，不能依赖备注进行分类。
- 增加充值积分后自动生成充值明细；扣减充值积分后自动生成特殊业务记录。
- 只有“退款扣回”显示退款资料入口；其他扣减需先修改业务性质并保留审计记录。
- 退款均由财务线下对公转账。退款金额、日期、转账流水号和原因完整后才显示“已退款”。
- 特殊业务使用独立 `SPC-` 编号，不复用积分流水号；算力账户归属类型仅为用户或团队。
- 人民币金额与积分独立；没有可靠来源的字段显示并导出“/”，真实零值显示为 `0`。
- 支付手续费由财务在第三方商家后台核对，不进入本后台。
- 系统事实不可修改；财务档案和退款补充资料保留完整变更记录。

## 看板模块

1. 客户及财务档案：个人或企业主体、联系方式、账户状态、合同和开票资料。
2. 充值明细：线上充值订单、套餐变更和后台充值积分增加。
3. 消费明细：真实消费流水、三类积分扣减、计量依据及关联业务。
4. 月度汇总：按当前筛选动态汇总；金额口径不完整时显示“/”并标明缺失数。
5. 特殊业务：后台手动扣减、退款、过期清零、调账或冲红、未支付订单取消。

## 主要交互

- 新建或编辑财务档案，并关联现有线上对象。
- 在算力账户调整充值积分并选择结构化业务性质。
- 修改扣减业务性质，并从“退款扣回”记录补充线下退款资料。
- 按月份、客户类型、线上对象、业务类型、来源和状态组合筛选。
- 按当前筛选导出五个 Excel 工作表。

原型中的保存与导出仅演示交互，不连接真实财务系统。
