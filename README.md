# 塑梦AI 财务数据看板原型

本项目用于演示总后台“财务数据看板、人工维护及 Excel 导出”的产品方案。

- 在线原型：https://thedeathsheep.github.io/sumeng-finance-data-export-prototype/
- 需求事项：https://linear.app/duckduck2/issue/PROD-72

代码推送到 `main` 后，由 GitHub Actions 自动构建并发布到 GitHub Pages。

## 核心口径

- 线上产品对象仍为用户、团队和算力账户；企业或渠道身份只作为财务档案。
- 财务客户类型固定为“个人 / 企业”，不新增企业用户类型。
- 系统数据标记为“系统同步”，不可在财务看板内直接改写。
- 线下资料标记为“人工录入”，允许编辑或作废，不允许物理删除。
- 没有数据的字段统一显示并导出“/”。
- 积分与人民币金额分开记录，没有确认换算规则时不自动折算。
- 财务看板不直接修改积分；积分调整仍在算力账户中完成并关联真实流水。
- 权限沿用总后台现有角色和权限配置机制。

## 看板模块

1. 客户及财务档案：客户主体、联系方式、账户状态、合同和开票资料。
2. 充值明细：线上订单、充值积分调整及人工维护的线下充值资料。
3. 消费明细：系统积分流水、三类积分扣减、计量依据及业务关联。
4. 月度汇总：按筛选条件动态汇总未作废的系统和人工记录。
5. 特殊业务：退款、清零、调账或冲红、支付手续费和取消订单。

## 手续费口径

- 用户实付金额保持原值，不扣除第三方手续费。
- 财务从第三方商家后台取得账单后，按月份和支付渠道登记手续费合计。
- 手续费是平台级费用，不关联单个客户、账户、订单或积分流水。
- 可选择上传支付渠道账单；没有附件时显示“/”。

本项目仅为交互原型，不连接真实财务数据。
